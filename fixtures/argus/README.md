# Synthetic Argus fixtures

These records are synthetic examples based on the attributes documented in the
DOCA Argus 3.4 service guide. They are not captured Argus output and do not
prove the exact product wire format.

Hostnames, interface names, MAC addresses, and network addresses are fictional.
The IP addresses use the documentation-only ranges reserved by RFC 5737.

The adapter preserves every complete source record. A reviewed hardware capture
must replace or supplement these fixtures before Contour claims compatibility
with an Argus release.
